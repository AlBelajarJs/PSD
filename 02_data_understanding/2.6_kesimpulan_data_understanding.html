2.6 Kesimpulan Data Understanding#

Dokumen ini merangkum seluruh temuan utama, sintesis karakteristik statistik, dan evaluasi kualitas data dari tahapan BAB 2 — DATA UNDERSTANDING untuk analisis kualitas udara di Kecamatan Wonoayu, Kabupaten Sidoarjo (periode 31 Agustus 2025 s.d. 31 Agustus 2026).

1. Matriks Sintesis Temuan Data Understanding#

Aspek Analisis

Temuan Utama pada Data Wonoayu

Implikasi Metodologis

Akuisisi Data Satelit

Berhasil mengumpulkan 366 observasi harian untuk 6 parameter polutan (\(\text{NO}_2, \text{CO}, \text{HCHO}, \text{SO}_2, \text{O}_3, \text{CH}_4\)) via openEO Sentinel-5P TROPOMI berbasis AOI wonoayu.geojson.

Dataset memiliki representasi spasial agregat yang valid untuk seluruh wilayah kecamatan.

Integritas & Skema Basis Data

Berhasil melakukan DDL dan ingest ke cloud database PostgreSQL Aiven dengan tipe data DOUBLE PRECISION (Float 53-bit).

Ketelitian angka desimal mikro (\(10^{-5}\text{ mol/m}^2\)) terjaga penuh dari risiko pembulatan otomatis (floating-point truncation).

Tingkat Kelengkapan Data

Teridentifikasi 264 data valid (\(72.13\%\)) dan 102 data kosong (\(27.87\%\)) yang disebabkan oleh tutupan awan (cloud masking) selama musim hujan.

Diperlukan prosedur Imputasi Missing Value berbasis kontinuitas deret waktu (Interpolasi Linear) pada BAB 3.

Karakteristik Distribusi Statistik

Distribusi data bersifat Right-Skewed (\(\text{Skewness} = +0.876\)) dan Leptokurtik (\(\text{Kurtosis} = +1.858\)).

Konsentrasi polutan mayoritas berada di tingkat rendah-sedang, namun memiliki probabilitas kemunculan nilai puncak ekstrem yang nyata.

Identifikasi Nilai Pencilan

Teridentifikasi beberapa pencilan atas (\(\text{Max} = 0.00009577\text{ mol/m}^2 > \text{Upper Fence } 0.00006848\), \(Z = +4.23\)).

Pencilan merefleksikan dinamika emisi transportasi logistik koridor Wonoayu dan fenomena meteorologis inversi suhu, bukan kegagalan instrumen satelit.

2. Kesiapan Menuju BAB 3 (Data Preprocessing)#

Hasil pemahaman data menunjukkan bahwa dataset siap memasuki tahapan BAB 3 — DATA PREPROCESSING, dengan fokus penanganan:

  1. Pemulihan Sinyal Deret Waktu Lengkap: Menghubungkan titik-titik data sebelum dan sesudah interval kosong menggunakan metode 3.3.1 Interpolasi Linear untuk menghasilkan 366 baris waktu kontinu penuh.

  2. Standardisasi Format: Memastikan konsistensi indeks kalender harian (\(\Delta t = 1\text{ hari}\)) tanpa ada tanggal yang terlewati.

  3. Validasi Kualitas Data Bersih: Memverifikasi bahwa data hasil imputasi bebas dari NaN serta siap digunakan sebagai masukan algoritma ekstraksi fitur deret waktu (BAB 4 — FEATURE EXTRACTION).
